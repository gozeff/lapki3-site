Как стирать и сушить

Перед первым использованием обязательно постирайте и высушите полотенце и мочалку, следуя инструкции

Машинная стирка

Производите стирку при температуре не выше 40°C. Задавайте медленный режим вращения барабана при полоскании и отжиме. Для стирки используйте средства для стирки детских вещей. Для дополнительной мягкости используйте кондиционер для белья

Ручная стирка

Производите стирку при температуре не выше 40°C, не допуская значительных колебаний температуры. Не подвергайте значительному механическому воздействию при ручном отжиме

  • Не отбеливайте полотенце во избежание потери цвета цветных элементов. Для цветных полотенец используйте средства для стирки цветных тканей. Химчистка запрещена

  • Машинная сушка допускается при низких температурах и низких оборотах барабана

  • Для сохранения вида изделия применяйте вертикальную сушку. Для сушки вы можете использовать петельку на капюшоне изделия

  • Можно гладить само полотенце и его велюровые элементы при низкой температуре до 150 градусов
